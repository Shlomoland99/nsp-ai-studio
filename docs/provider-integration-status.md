# Provider integration status

The registry includes the requested systems, but provider availability differs:

- ComfyUI, Gemini/Nano Banana, Canva Connect, PixVerse, and HeyGen have developer integration paths.
- Google Flow is primarily a creator UI; any automation route must remain explicitly experimental and account-authorized.
- Midjourney is listed for catalog/routing purposes; do not use unofficial automation without reviewing its terms.
- Seedance 2.5, Seedream, and Happy Horse require the specific vendor/API endpoint and account credentials selected for deployment.
- Ponytail could not be matched confidently to a canonical developer product name; it is retained as an explicit placeholder until the exact vendor is identified.

All credentials belong in deployment secrets. The public repository contains no keys.
