# Microsoft and creative-provider map

## Microsoft

The provider catalog includes Microsoft Foundry, Phi, Azure AI Speech,
and MAI Voice. Microsoft Foundry provides a managed model catalog; Azure
Speech provides speech recognition, synthesis, and translation.

“Microsoft Voicebox” is not the correct name: Voicebox is a Meta AI research
model. It is listed only as a research boundary and is not represented as a
working Microsoft API.

## Repository access model

The repository may be public for reading, cloning, and forking. Public access
does not grant push permission. Only people explicitly added as
collaborators can write to the original repository.

The repository includes an owner-review file and contribution rules so
changes are reviewed by the owner. For strong enforcement, the owner must
enable a protected main branch in GitHub Settings and require pull-request
review. People who only need to use the software should clone or fork it;
they should not be collaborators on the original repository.
